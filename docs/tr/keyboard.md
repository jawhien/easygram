# Ana Pencere

## Genel

* Alt + 1 - Sohbet listesine git.
* Alt + 2 - Kişi listesine git.
* Alt + F - Sohbet klasörü seçimi.
* Control + Shift + F - Arama penceresini aç.
* Control + M - Profilimi aç.
* Control + P - Ayarları aç.
* Control + F1 - Günlüğü aç.
* F1 - Hakkında.

## Sohbet Listesi

* Control + Shift + Delete - Sohbet geçmişini temizle.

# Sohbet Penceresi

## Genel

* Enter veya CTRL + Enter - Mesaj gönder (uygulama ayarlarına bağlı olarak).
* Alt + 1'den 0'a kadar rakamlar - Son on mesajı oku (1 en son mesaj, 0 sondan onuncu mesajdır). Çift basıldığında odağı o mesaj üzerine getirir.
* Alt + E - Mesaj düzenleyiciye git.
* Alt + T - Konu (topic) seçimi.
* Alt + W - Mesaj listesine git.
* Alt + A - Dosya ekle.
* Alt + S - Emoji ekle.
* Alt + V - Sesli mesaj kaydet.
* Sesli mesaj kayıt penceresinde Enter - Sesli mesajı gönder.
* Alt + F10 - Bir sonraki okunmamış bahsetmeye (mention) git.
* Alt + F11 - Bir sonraki okunmamış tepkiye git.

## Список сообщений

* Enter - Seçili mesajdaki ilk bağlantıyı aç, sesli mesajı veya diğer medya dosyalarını oynat.
* Boşluk (Space) - "Mesaj Bilgisi" penceresini aç.
* Alt + F - Mesajı ilet.
* Alt + R - Mesajı yanıtla.
* Alt + Q - Alıntılanan mesajı oku. Çift basıldığında alıntılanan mesaja gider.
* Alt + End - Son mesaja git.
* Control + End - Son mesaja git (Alt + End ile aynı).
* Delete - Mesajı sadece kendinden sil.
* Shift + Delete - Mesajı herkesten sil.
* CTRL + C - Mesajı panoya kopyala.
* Control + S - Dosyayı indirilenlere kaydet.
* Control + Shift + S - Dosyayı farklı kaydet.
* Ctrl + Shift + Enter - Mesajdaki tüm mevcut bağlantıların listesini açar.
* Ctrl + Enter - İlk öncelikli bağlantıyı açar veya öncelik belirlenemezse listeyi gösterir. Öncelik algoritması: Tek bir bağlantı varsa en yüksek önceliğe sahiptir; birden fazla varsa, metin açıklaması olmayan bağlantılar önceliklidir.

# Medya Oynatıcı Kontrolleri

* F5 - Sesi azalt.
* Shift + F5 - Oynatma hızını azalt.
* F6 - Sesi artır.
* Shift + F6 - Oynatma hızını artır.
* F7 - Oynat / Duraklat.
* Shift + F7 - Geri sar.
* F8 - Durdur.
* Shift + F8 - Иleri sar.
* F9 - Medya oynatıcı penceresini aç.

# Medya Oynatıcı Penceresi

* Sağ Ok - 5 saniye ileri sar.
* CTRL + Sağ Ok - 10 saniye ileri sar.
* Alt + Sağ Ok - 15 saniye ileri sar.
* Shift + Sağ Ok - Oynatma hızını artır.
* Sol Ok - 5 saniye geri sar.
* CTRL + Sol Ok - 10 saniye geri sar.
* Alt + Sol Ok - 15 saniye geri sar.
* Shift + Sol Ok - Oynatma hızını azalt.
* Yukarı Ok - Sesi artır.
* Shift + Yukarı Ok - Varsayılan oynatma hızı.
* Aşağı Ok - Sesi azalt.
* Boşluk (Space) - Oynat / Duraklat.
* CTRL + Shift + E - Geçen süreyi seslendir.
* CTRL + Shift + R - Kalan süreyi seslendir.
* CTRL + Shift + T - Toplam süreyi seslendir.

# Arama Penceresi

* Alt + E - Giriş alanına git.
* Alt + R - Sonuç listesine git.
* Control + Delete - Arama geçmişini temizle.
