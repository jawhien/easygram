# Main Window

## General

* Alt + 1 - Go to the chat list.
* Alt + 2 - Go to the contact list.
* Alt + F - Select chat folder.
* Control + Shift + F - Open the search window.
* Control + M - Open my profile.
* Control + P - Open settings.
* Control + F1 - Open the log.
* F1 - About the program.

## Chat List

* Control + Shift + Delete - Clear chat history.

# Chat Window

## General

* Enter or CTRL+Enter - Send message (depending on application settings).
* Alt + digits from 1 to 0 - Read the last ten messages, where 1 is the most recent message and 0 is the tenth from the end. Double-press to focus on the message.
* Alt + E - Move to message editor.
* Alt + T - Select topic.
* Alt + W - Move to message list.
* Alt + A - Attach file.
* Alt + S - Insert emoji.
* Alt + V - Record voice message.
* Enter in the voice message recording window - Send voice message.
* Alt + F10 - Go to the next unread mention.
* Alt + F11 - Go to the next unread reaction.

## Message List

* Enter - Open the first link in the selected message, play voice message, or other media file.
* Space - Open "Message Info" window.
* Alt + F - Forward message.
* Alt + R - Reply to message.
* Alt + Q - Read quoted message. Double-press to jump to the quoted message.
* Alt + End - Go to the last message.
* Control + End - Go to the last message (same as Alt + End).
* Delete - Delete message for yourself only.
* Shift + Delete - Delete message for everyone.
* CTRL + C - Copy message to clipboard.
* Control + S - Save file to Downloads.
* Control + Shift + S - Save file as.
* Ctrl + Shift + Enter - Opens a list of all available links in the message.
* Ctrl + Enter - Opens the first priority link or shows a list if no priority link is determined. Priority is defined as follows: if there is only one link, it has the highest priority; if there are multiple, links without text descriptions take priority.

# Media Player Controls

* F5 - Decrease volume.
* Shift + F5 - Decrease playback speed.
* F6 - Increase volume.
* Shift + F6 - Increase playback speed.
* F7 - Play/Pause.
* Shift + F7 - Rewind.
* F8 - Stop.
* Shift + F8 - Fast forward.
* F9 - Open media player window.

# Media Player Window

* Right Arrow - Fast forward 5 seconds.
* CTRL + Right Arrow - Fast forward 10 seconds.
* Alt + Right Arrow - Fast forward 15 seconds.
* Shift + Right Arrow - Increase playback speed.
* Left Arrow - Rewind 5 seconds.
* CTRL + Left Arrow - Rewind 10 seconds.
* Alt + Left Arrow - Rewind 15 seconds.
* Shift + Left Arrow - Decrease playback speed.
* Up Arrow - Increase volume.
* Shift + Up Arrow - Default playback speed.
* Down Arrow - Decrease volume.
* Space - Play/Pause.
* CTRL + Shift + E - Announce elapsed time.
* CTRL + Shift + R - Announce remaining time.
* CTRL + Shift + T - Announce total time.

# Search Window

## General

* Alt + E - Move to the input field.
* Alt + R - Move to the results list.
* Control + Delete - Clear search history.
