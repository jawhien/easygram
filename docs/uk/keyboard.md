# Головне вікно

## Загальні

* Alt + 1 - Перейти до списку чатів.
* Alt + 2 - Перейти до списку контактів.
* Alt + F - Вибір папки з чатами.
* Control + Shift + F - Відкрити вікно пошуку
* Control + M - Відкрити мій профіль
* Control + P - Відкрити налаштування.
* Control + F1 - Відкрити журнал.
* F1 - Про програму.

## Список чатів

* Control + Shift + Delete - Очистити історію чату

# Вікно чату

## Загальні

* Enter або CTRL+Enter - надіслати повідомлення (залежно від налаштувань програми)
* Alt+цифри від 1 до 0 - читання останніх десяти повідомлень, де цифра 1 — найостанніше повідомлення, а 0 — десяте з кінця. За подвійного натискання встановлює фокус на це повідомлення.
* Alt+E - перейти до редактора повідомлення
* Alt + T - Вибір топіка.
* Alt+w - перейти до списку повідомлень
* Alt+A - прикріпити файл
* Alt+S - вставити емодзі
* Alt+V - записати голосове повідомлення
* Enter у вікні запису голосового повідомлення - надіслати голосове повідомлення.
* Alt + F10 - Перейти до наступної непрочитаної згадки.
* Alt + F11 - Перейти до наступної непрочитаної реакції.

## Список повідомлень

* Enter - відкрити перше посилання у вибраному повідомленні, відтворити голосове повідомлення або інший медіафайл
* Пробіл - відкрити вікно «Інформація про повідомлення»
* Alt + F - Переслати повідомлення.
* Alt+R - відповісти на повідомлення
* Alt + Q - Прочитати цитоване повідомлення. За подвійного натискання — перейти до цитованого повідомлення.
* Alt+End - перейти до останнього повідомлення
* Control + End - Перейти до останнього повідомлення, те саме, що й Alt + End.
* Delete - видалити повідомлення лише у себе
* Shift+Delete - видалити повідомлення у всіх користувачів
* CTRL+C - скопіювати повідомлення до буфера обміну,
* Control + S - Зберегти файл у завантаження.
* Control + Shift + S - Зберегти файл як.
* Ctrl+shift+enter - відкриває список усіх доступних посилань у повідомленні.
* ctrl+enter - відкриває перше пріоритетне посилання або показує список, якщо пріоритетне посилання визначити не вдалося. Пріоритет визначається за таким алгоритмом: якщо посилання одне, воно має найвищий пріоритет, якщо посилань кілька, пріоритет мають посилання без текстового опису.

# Керування медіаплеєром

* F5 - зменшити гучність
* Shift+F5 - зменшити швидкість відтворення
* F6 - збільшити гучність
* Shift+F6 - збільшити швидкість відтворення
* F7 - Відтворення/Пауза
* Shift+F7 - перемотування назад
* F8 - зупинити
* Shift+F8 - перемотування вперед
* F9 - відкрити вікно медіаплеєра.

# Вікно медіаплеєра

* Стрілка вправо - перемотування вперед на 5 секунд
* CTRL+стрілка вправо - перемотування вперед на 10 секунд
* Alt+стрілка вправо - перемотування вперед на 15 секунд
* Shift+стрілка вправо - збільшити швидкість відтворення
* Стрілка вліво - перемотування назад на 5 секунд
* CTRL+стрілка вліво - перемотування назад на 10 секунд
* Alt+стрілка вліво - перемотування назад на 15 секунд
* Shift+стрілка вліво - зменшити швидкість відтворення
* Стрілка вгору - збільшити гучність
* Shift+стрілка вгору - швидкість відтворення за замовчуванням
* Стрілка вниз - зменшити гучність
* Пробіл - відтворення/пауза
* CTRL+Shift+E - озвучити минулий час
* CTRL+Shift+R - озвучити час, що залишився
* CTRL+Shift+T - озвучити загальний час.

# Вікно пошуку

* Alt + E - Перейти до поля введення.
* Alt + R - Перейти до списку результатів.
* Control + Delete - Очистити історію пошукових запитів.
